# Sub-topic Intro Skill

Purpose:
Create a short introduction for a sub-topic inside a main topic, for example SQL Server -> DDL.

Requirements:
- Visually inherit the selected main-topic intro family.
- Make the sub-topic immediately understandable.
- Keep branding present but subordinate to the educational subject.
- Use motion and typography that can be recognized as part of the same series.
- Support narration, music, and sound effects.
- Generate React/TypeScript for Remotion.
