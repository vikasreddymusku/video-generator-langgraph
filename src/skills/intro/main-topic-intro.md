# Main Topic Intro Skill

Purpose:
Create a short introductory video for a main course topic.

Requirements:

- Create a professional Tinitiate-branded introduction.
- Use the supplied company logo/reference when provided.
- Introduce the main topic clearly.
- Support animated typography and logo animation.
- Support voice narration.
- Support background music and sound effects.
- The visual style should be suitable for educational technology content.
- The generated result must be suitable for rendering with Remotion.
- The LLM should generate React/TypeScript code for the video.
