# Reference-Driven Video Generation Skill

Purpose:
Use user-supplied text, images, videos, and other references as design constraints.

Rules:
- Text references provide content and factual requirements.
- Image references provide visual language, composition, branding, color, typography, and asset clues.
- Video references provide motion language, pacing, transitions, camera movement, sequencing, and timing clues.
- Do not copy a reference literally unless the user explicitly requests reproduction and the assets are authorized.
- Extract reusable characteristics: pacing, layout, transition style, visual hierarchy, lighting, typography, and sound relationship.
- Preserve explicit brand requirements over generic stylistic suggestions.
- If references conflict with the user's explicit prompt, prioritize the explicit prompt and note the conflict in the generation plan.
