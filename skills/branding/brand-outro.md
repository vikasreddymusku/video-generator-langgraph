# Brand Outro Skill

Purpose:
Create an outro that belongs to the same visual family as the selected branding/main-topic/sub-topic intro.

Requirements:
- Resolve the visual story rather than simply displaying a logo.
- Reuse the family's typography, color language, motion vocabulary, and sound identity.
- Support CTA or closing text when supplied.
- Return to Tinitiate branding cleanly.
- Generate React/TypeScript for Remotion.
