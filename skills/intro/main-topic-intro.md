# Main Topic Intro Skill

Purpose:
Create a short branded introduction for a main course topic such as SQL Server.

Inputs:
- Main topic name
- Optional narration/script
- Optional image/video references
- Optional Tinitiate brand assets
- Optional voice/style instructions

Requirements:
- Establish Tinitiate branding.
- Clearly reveal the main topic.
- Support first-person and second-person narration.
- Coordinate typography, logo motion, narration, music, and transitions.
- Use a short, deliberate structure rather than a generic title card.
- Generate React/TypeScript suitable for the existing Remotion project.
- Preserve the selected visual family so related sub-topic intros and outros can match.
