# Tinitiate Branding Skill

Purpose:
Maintain a consistent Tinitiate visual identity across branding intros, topic intros, sub-topic intros, and outros.

Requirements:
- Treat supplied Tinitiate logo/brand assets as authoritative.
- Keep branding recognizable without making the logo compete with the main topic.
- Maintain a dark, premium, technology-oriented visual language when consistent with the supplied references.
- Use consistent typography, spacing, transition language, and sound identity across a variation family.
- Branding intro should establish the Tinitiate identity first.
- Main-topic and sub-topic intros should inherit the same visual family while giving the topic more visual priority.
- Outro should resolve back into the same family so the sequence feels like one designed system.
